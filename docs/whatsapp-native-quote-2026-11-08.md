# WA-I09-QUOTE — ציטוט WhatsApp מקורי בהודעות טקסט

תאריך 08.11.2026. Pulse של שירת הנבל, Base44 687d1de6659eff83e9c034f7.

## מוצר וממשק
בלשונית כפתורים בתוך עריכת תבנית SUPPLIER_PENDING_REMINDER קיימת מעתה אפשרות בחירה "ציטוט הודעת השיבוץ המקורית בתזכורת". האופציה דורשת בחירה ושמירה יזומה של מנהל; היא כבויה כברירת מחדל ולא משנה הודעות שכבר בתור. היא מחליפה את הכפתורים באותה תבנית, משום ש-Green אינו מתעד ציטוט מקורי יחד עם SendInteractiveButtons. ביטול הבחירה מחזיר כפתור קישור סטנדרטי.

## אלגוריתם אבטחה ואמינות
1. אין בדיקות Green להודעה שלא בחרו לה ציטוט בתבנית ושאין לה snapshot קפוא ב-Outbox. גרסת snapshot חדשה 3; כל גרסאות 1/2 והכפתורים הישנים נשארים תקינים.
2. רק תזכורת אישור שיבוץ ממתין, טקסט, Green, צ'אט פרטי, מזהי אירוע/שירות/ספק נכונים, ללא כפתורי תגובה או אישור שיבוץ, חשבון Green המקורי.
3. קריאת EventService אחת מאמתת שהספק עוד משובץ ובסטטוס pending, שיטת durable_v1, ושכוונת השיבוץ האחרונה שייכת לאותה גרסת שיבוץ בדיוק.
4. קריאת Outbox ממוקדת מחפשת את שתי הודעות השיבוץ האחרונות. רק האחרונה מתקבלת אם היא accepted, עם מפתח idempotency תואם, חשבון Green ואותו צ'אט, זהות ספק ושירות וגרסה מאומתת. כפילות או הודעה ישנה נחסמות.
5. רק אחרי אימות השרת מותר לבצע POST יחיד ל-GetMessage של Green, ללא retry, עם זמן המתנה מרבי 1.8 שניות. תשובה חייבת להראות הודעת API יוצאת שהתקבלה/נקראה, בצ'אט הנכון, שלא נמחקה, עם חותמת זמן עד 90 יום.
6. מתכנן הציטוט הקיים מאמת מחדש חשבון, צ'אט, חברה, ספק, שירות וגרסה. אם הכול תקין, מתווסף quotedMessageId לקריאת sendMessage הרגילה. אחרת נשלח טקסט רגיל. תמיד לכל היותר ניסיון שליחה אחד, אין שינוי של שיבוץ ואין cron/webhook/עבודה ברקע חדשים.
7. גם ציטוט עם GetMessage תקין אינו מבטיח מסירה: Green מתעד שמזהה ציטוט לא תקין עלול להחזיר 200 ללא מסירה. אין לפרש קבלה על ידי API כהוכחת מסירה ואין לבצע שליחה שנייה כאשר התוצאה unknown.
